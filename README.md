# 💼 GB Employment Data

This dashboard explores changes in **GB employment between 2011 and 2014**, with particular focus on industries, sub-industries and geographic differences.

The dashboard includes:

- Employment change by industry
- Employment percentage change by city
- Top sub-industries
- Comparison between Liverpool and Manchester
- Geographic employment patterns
- Interactive industry and city filters

The combination of bar charts, a map, treemap and comparative visualisations provides a clear overview of employment changes from several perspectives.

The Global Health dashboard was created using health data covering countries and continents.

The analysis explores:

- BMI and life expectancy relationships

- Relationships between BMI, blood pressure and cholesterol

Interactive filters allow different countries, continents and demographic categories to be explored.

## 🧮 Calculated Fields

Calculated fields were used to create additional analytical measures from the original dataset.

Examples included:

**Total Cancer Cases**

```text
Liver Cancer + Lung Cancer + Stomach Cancer
```

**Cancer Rate**

```text
Total Cancer Cases / Population
```

These calculated measures allowed the original health data to be extended and analysed from additional perspectives.

---

## 🔍 Relationship Analysis

Scatter plots were used to investigate relationships between health measures such as:

- Life expectancy and BMI
- BMI, blood pressure and cholesterol

This helped demonstrate how Tableau can be used not only for reporting values, but also for investigating whether relationships or patterns exist between variables.

# 🎵 Spotify Findings

This dashboard analyses Spotify track data to explore relationships between **genre, artist popularity, tempo and danceability**.

The analysis included:

- Average popularity by genre
- Top 10 artists
- Average tempo by genre
- Popularity compared with danceability

The project demonstrates how visualisation can be used to explore behavioural and entertainment data and identify patterns that may not be obvious from the raw dataset alone.
